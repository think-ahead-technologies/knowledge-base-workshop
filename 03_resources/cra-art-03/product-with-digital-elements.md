# CRA product with digital elements

A "Produkt mit digitalen Elementen" (point 1) is a software or hardware product together with its remote data processing solutions ("Datenfernverarbeitungslösungen"), including software or hardware components placed on the market separately. The building blocks are defined too: "Software" (4) is the part of an electronic information system consisting of computer code; "Hardware" (5) is a physical electronic information system (or parts of one) able to process, store or transmit digital data; "Komponente" (6) is software or hardware intended for integration into an electronic information system; "elektronisches Informationssystem" (7) is a system, including electrical or electronic equipment, that can process, store or transmit digital data.

Connection terms: "logische Verbindung" (8) is a virtual representation of a data connection via a software interface; "physische Verbindung" (9) is a connection via physical means (electrical, optical, mechanical interfaces, wires, radio waves); "indirekte Verbindung" (10) is a connection that is not direct but via a larger system that itself connects to the device or network; "Endpunkt" (11) is a network-attached device serving as an access point to that network.

Commission guidance (C(2026) 5252 final, non-binding, as summarized on the page):
- 2.2: software is a product only if provided to the user and executed on the user's system. Locally installed apps, browser extensions and locally run web-tech desktop apps are products; browser-only web apps, PWAs and informational websites are not (recitals 11 and 12) - they only count as remote data processing if they support a product function.
- 2.3: both source code and machine code are "Software" under point 4; what matters is whether it is supplied in the course of a commercial activity.
- 2.4: separately obtained drivers and companion apps form a single product with the hardware when required for its intended functions (network printer + driver, wearable + companion app); delivery channel is irrelevant.
- 2.5: CRA scope requires a data connection - binary states deliberately encoded as information by a sender and decodable as data by a receiver. Signals that merely switch a function or supply power do not create CRA scope.
