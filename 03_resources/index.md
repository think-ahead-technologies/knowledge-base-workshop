# Resources Hub

Static documents and required online material, one folder each under
`03_resources/<slug>/`. A resource exists to feed domains with context: domain,
feature and rule notes link to it with `context` and say in the `link-info` why
or in which way they need it. The original bytes stay untouched in
`03_resources/<slug>/raw/` (excluded from the graph) next to the notes derived
from them.
