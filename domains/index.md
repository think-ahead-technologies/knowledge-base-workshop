# Domains Hub

Working domains, one folder each under `domains/<domain>/`:

```
domains/<domain>/
  index.md              the domain: purpose, scope, vocabulary, repos, context
  features/<feature>.md one note per feature the domain provides
  rules/<rule>.md       one note per rule that holds in the domain
```

A domain points at the code that implements it with `implemented-in` links to
repository notes, and at the material that explains it with `context` links to
resource notes. Both links carry a `link-info` that says why.
